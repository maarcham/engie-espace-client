# ENGIE – Espace Client (démo)

Page unique sur le thème ENGIE présentant l'espace client "Mes factures" : consultation des factures d'électricité et de gaz.

> Projet de démonstration / maquette, non affilié à ENGIE. Logo réinterprété (mosaïque de carrés colorés), non issu des assets officiels de la marque.

## Contenu

- [index.html](index.html) — espace client : liste des factures avec filtres (année, statut, énergie)
- [assets/css/style.css](assets/css/style.css) — thème visuel ENGIE (navy pétrole + verts/mosaïque)

## Lancer le projet

```bash
npm install
npm run dev
```

Le serveur de développement (Vite) démarre sur `http://localhost:3000`.
