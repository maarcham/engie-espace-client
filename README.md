# ENGIE – Espace Client (démo)

Landing page statique sur le thème ENGIE présentant un espace client permettant de consulter ses factures d'électricité et de gaz.

> Projet de démonstration / maquette, non affilié à ENGIE. Logo réinterprété (mosaïque de carrés colorés), non issu des assets officiels de la marque.

## Contenu

- [index.html](index.html) — landing page (présentation, accroche, aperçu des factures)
- [factures.html](factures.html) — espace client : liste des factures avec filtres (année, statut, énergie)
- [assets/css/style.css](assets/css/style.css) — thème visuel ENGIE (navy pétrole + verts/mosaïque)

## Lancer le projet

Aucune dépendance : ouvrez simplement [index.html](index.html) dans un navigateur, ou servez le dossier avec un serveur statique, par exemple :

```bash
npx serve .
```
